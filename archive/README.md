# Archive

現在は使用していない設定の保管場所です。

`archive/` 配下のファイルは、セットアップスクリプトやシンボリックリンクの対象にしません。
再利用する場合は現行ディレクトリへコピーし、内容を確認してから編集します。

| アーカイブ | 退役日 | 内容 | 理由 | 現行設定 |
| --- | --- | --- | --- | --- |
| `retired/2026-07-26-old-cleanup/` | 2026-07-26 | 各ディレクトリの `old/`、旧Neovim・Sheldon・Starship設定 | 古い設定の一括整理 | 各ツールの通常ディレクトリ |

## 運用ルール

- アーカイブしたファイルは原則として変更しない。
- 現行設定、セットアップ処理、シンボリックリンクから参照しない。
- 再利用時は現行ディレクトリへコピーし、差分を確認してから反映する。
- 使用中の設定バリエーションは `archive/` ではなく `profiles/` または `presets/` で管理する。
- ログ、キャッシュ、秘密情報は保管しない。
- 完全に不要になったファイルは Git 履歴に任せて削除する。
